## Headline findings

- FastFlow: **99.4% AUC on MVTec AD**, with high inference efficiency.
- Chest CT: **AUROC > 0.90 for 18 abnormalities**.
- Transformer models: **F1 > 0.96** in a multimodal setting (best case reported).
- These numbers come from different datasets and are not directly comparable — judge by AUC, F1 and recall on the anomaly class, not accuracy.
